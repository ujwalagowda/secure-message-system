🔐 How RSA Encryption Works in This System

🗝️
Key Pair Generation
Each user gets a unique RSA-2048 key pair on registration. Public key is shared; private key stays on the server.
🔒
Encryption
Messages are encrypted with the recipient's public key. Only the recipient's private key can decrypt them.
🔓
Decryption
Decryption uses the recipient's private key server-side. Plaintext never stored; private key never exposed.
📐
Algorithm
RSA-2048 · OAEP/SHA-256 padding · Max 190 chars. Java KeyPairGenerator + Cipher APIs.
